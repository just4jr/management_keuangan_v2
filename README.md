My Personal Financial App
🚀 Project Overview
Welcome to my Personal Financial App! This is a full-stack application built to help users manage their income and expenses, set budgets, and visualize their financial data. The application is designed with a clean, modern user interface for a smooth user experience.

✨ Features
Dashboard: A quick overview of your total income, expenses, and remaining funds.

Transactions: Record, view, edit, and delete income and expense transactions. Filter and sort transactions by date, month, and amount.

Budgets: Set up monthly budgets for different categories. Track your spending and see your remaining budget with a progress bar.

Profile: Manage your personal information, update your profile picture, and change your details.

Authentication: Secure user registration and login using JSON Web Tokens (JWT) and encrypted passwords.

🛠️ Technology Stack
The project is a full-stack application built with the following technologies:

Frontend
React.js: The core library for building the user interface.

React Router: For handling client-side routing and navigation.

Tailwind CSS: A utility-first CSS framework for fast and responsive styling.

Recharts: A React charting library used for the pie chart.

SweetAlert2: For beautiful and customizable pop-up messages.

Backend
Node.js: The runtime environment for the server.

Express.js: A fast and minimalist web framework for the backend API.

MySQL: The relational database used to store all application data.

mysql2/promise: A MySQL driver that uses Promises for cleaner asynchronous code.

jsonwebtoken: For creating and verifying JWTs to secure API routes.

bcryptjs: A library for hashing and securing user passwords.

dotenv: To manage environment variables securely.
